## I-01 — Metadata cannot substitute for lived organizational/political context

**Sources:** bruce, michelle, stephen  
**Evidence:** michelle:0028, stephen:0022, bruce:0035  
**Counter-evidence:** david:0040 — David frames the same loss of contextual control as a generative feature of open, relational data rather than a threat to validity.  
**Opportunity:** Repositories should mandate or strongly incentivize rich narrative 'Read Me' context files (organizational change, funding, political climate) alongside standard metadata fields, rather than treating metadata as sufficient documentation.
