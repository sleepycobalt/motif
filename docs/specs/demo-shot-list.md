# Motif — Community demo clip, shot list

*26 seconds, silent, no narration. Recorded by Eric. Structure: stored result → board →
critique, so nothing waits on a run and the clip costs no API spend.*

## Before you record

- **Record after the v3 restyle ships.** On the current build the clip would show
  Figma's default blue and Inter, which is the thing the redesign exists to fix.
- **Format:** 1920 × 960, 30 fps, H.264 `.mp4`, no audio track. Same aspect as the
  carousel images, so the clip sits in the strip without letterboxing.
- **File and account hygiene** (the no-personal-info rule): a fresh FigJam file named
  `Motif demo`; no other tabs or files in frame; sign out of nothing, but crop the
  export so the macOS menu bar, the Figma top bar with the file name and your avatar,
  the clock, and the browser tab strip are all outside the frame. Record a larger
  region and crop to the canvas plus the plugin panel in post.
- **Never in frame:** the key screen, any part of a key string, transcript file names
  that carry a participant's real name, the Figma multiplayer cursor label.
- **Setup:** open the plugin on a board that already holds the stored result from run
  `20260905-221749-C-hosted`. It opens on the result screen with Build board ready.
  Clear the canvas first so the board draws into empty space.
- **Cursor:** move it once per shot, slowly, and park it. No hunting, no overshoot. Cut
  the frames where the cursor searches for a button.

## Overlays

One line per shot, held for its full duration, set in Space Grotesk on ETOT blue at the
lower left, 48 px, with a 32 px margin. Same type as the carousel frames. No transitions
between overlays beyond a hard cut. If a shot reads without its overlay, drop it.

## Cut discipline

- Hard cuts only. No dissolves, no zoom transitions between shots, nothing that reads as
  a template.
- Two moments carry the product: the board drawing (shot 3) and the receipt-and-contested
  section (shot 4). If the clip runs long, take the seconds out of shots 1 and 5.
- The wait between clicking **Check this synthesis** and the verdict is a real few
  minutes. It is cut, not sped up — a time-lapse of a progress bar tells a viewer the
  tool is slow, which is a fact for the FAQ and not for the clip.
- No speed ramps anywhere. The board draw in shot 3 plays at its real speed; if it is
  slower than six seconds, trim the middle of the draw rather than accelerating it.
