# Part 3 notes — Motif for Figma

Running list of moments worth writing up for the part-3 case study (the hosted engine, the plugin as product, tiers, first users, first revenue). One dated line per moment. Numbers and quotes are copied from the file named in the line, never recalled.

- 2026-09-04 — Part 3 opened. Read `docs/specs/motif-figma-plugin.md` (v2, the commercial surface), `docs/specs/motif-mcp-server.md`, and `CONTRIBUTING.md`. Proposal written to `docs/specs/part3-build-plan.md` before any code; awaiting ruling on hosting, Design-editor timing, and payment rails.
- 2026-09-04 — Engine constraint for BYOK: `core/llm.py` builds one module-level `Anthropic()` from the environment (`client()`), so the hosted service cannot use a per-user key without an engine change. Proposed: a `contextvars.ContextVar` for the client, set per job, defaulting to the environment so the CLI and MCP local mode are untouched.
- 2026-09-04 — Why a job API rather than one request per tool: from `docs/part2-notes.md`, the refactor regression run took 440.9 s and the recorded 15-transcript run took 2,064.6 s ($4.88). Submit / stream / fetch survives proxies and a closed plugin window; the draft contract in `surfaces/mcp/remote.py` (synchronous calls) will be replaced.
- 2026-09-04 — Privacy line in the spec ("processed for the run and discarded; nothing stored") maps onto the logger's existing `redact=True`: digests instead of prompt bodies, no corpus snapshot. The hosted service keeps the processed corpus in memory for the job plus a short TTL, then drops it. Consequence: remote `motif_receipts` only works within the TTL; the plugin gets receipts inline in the insights and never needs the endpoint.
- 2026-09-04 — Editor gap: stickies and connectors are FigJam-only plugin-API nodes; the Design editor has sections but no stickies. The board writer needs a second renderer (frames and text) for Design. Proposed order: FigJam first, Design at the end of stage 3.
- 2026-09-04 — Payments constraint: Figma's payments API sells one-time purchases or subscriptions, not a consumable balance, so prepaid credits need an ETOT-owned ledger topped up by Stripe Checkout via webhook. Matches the spec's Stripe fallback. To verify against Figma's docs when the paid tier is built.
- 2026-09-04 — Discipline miss found: the PyPI publish session (commit `927120c`) appended notes to `docs/part2-notes.md` but no three-line entry to `docs/log.md`. Added retroactively today, marked as such.
- 2026-09-04 — Listing asset gap: the icon source ("the field thumbnail, reduced" in the spec) is not in the repo; `find` for thumb/icon/field returned nothing outside `.venv`.
- 2026-09-04 — Ruling from the user: Fly.io; Design renderer at the end of stage 3; Stripe Checkout with an ETOT ledger, designed in stage 1 and built only when the prerequisites are dated; add a per-IP concurrency cap and a per-job transcript size cap on the BYOK path; the listing icon comes from the Motif field thumbnail (user supplies it); commit and push at the end of every session.
- 2026-09-04 — Stage 1 built offline: `core/llm.py` gained a per-context client (`using_key`) so a hosted job runs on its caller's key; `core/config.py` accepts a context key in place of the env var; `surfaces/hosted/` (app.py job API, jobs.py registry with caps and TTL, credits.py ledger, Dockerfile, fly.toml, README); `surfaces/mcp/remote.py` rewritten as a client of the job API and the MCP server's five remote branches wired to it; `tests/test_hosted.py` (11 tests: service through the test client, remote client on a real port, MCP server as a subprocess in remote mode). Suite: 30 passed in 4.19 s.
- 2026-09-04 — Surprise, and the most important finding of the session: the logger's `redact=True` digested the prompts but kept the model's response text verbatim in `calls/*.json`, and synthesis responses quote the transcripts (the receipts). The privacy claim in the plan ("redacted logs contain no transcript text") was false until a test asserted it: `test_synthesize_job_end_to_end` failed with "transcript text leaked into 003_synthesis.json". Fixed in `core/logger.py`: response text is now a digest too; `data` is dropped from the record; usage, timing, and stop reason stay. Write-up angle: a privacy property is a test, not a sentence in a README.
- 2026-09-04 — Second bug caught by the tests: the remote client merged the engine's result over the job id, so `run_id` in the tool result was the guessable run directory name instead of the random job id that later calls need. Fixed (`_as_tool_result`).
- 2026-09-04 — Environment surprise: `.venv/bin/pip` has a shebang pointing at `/Users/zzz/opt/claude/agentic-loop/synth-loop/.venv/bin/python3`, the venv's original path before the repo was renamed. `.venv/bin/python -m pip` works; the `pip` shim does not. Second time an "installed" environment has turned out to be a claim.
- 2026-09-04 — Corpus size finding for the upload caps: the 17 sample `.docx` files are 28 MB (Jamie.docx 5,879,730 bytes) because each embeds three ~1.7 MB Google Sans fonts (`unzip -l`), while `data/processed/*.txt` totals 620 KB. Caps set at 12 MB per file and 64 MB per job; stage 2 should weigh extracting paragraphs in the plugin before upload rather than sending 37 MB of base64.
- 2026-09-04 — MCP SDK 2.x gotcha (second of the day): `call_tool(progress_callback=...)` must be an async function; a plain lambda raises "object NoneType can't be used in 'await' expression" inside the SDK's dispatcher, and the error only shows in captured logs.

Region set to `ord` (the machine's timezone is America/Chicago). Local smoke: `motif-hosted` on port 8765 answered `/healthz` with `{"ok":true,"paid_tier":false,"jobs":0}`. Not yet done: deploy, and the stage-1 QA gate (MCP server in remote mode synthesising the sample corpus against the deployed service).
