# Part 3 notes — Motif for Figma

Running list of moments worth writing up for the part-3 case study (the hosted engine, the plugin as product, tiers, first users, first revenue). One dated line per moment. Numbers and quotes are copied from the file named in the line, never recalled.

- 2026-09-04 — Part 3 opened. Read `docs/specs/motif-figma-plugin.md` (v2, the commercial surface), `docs/specs/motif-mcp-server.md`, and `CONTRIBUTING.md`. Proposal written to `docs/specs/part3-build-plan.md` before any code; awaiting ruling on hosting, Design-editor timing, and payment rails.
- 2026-09-04 — Engine constraint for BYOK: `core/llm.py` builds one module-level `Anthropic()` from the environment (`client()`), so the hosted service cannot use a per-user key without an engine change. Proposed: a `contextvars.ContextVar` for the client, set per job, defaulting to the environment so the CLI and MCP local mode are untouched.
- 2026-09-04 — Why a job API rather than one request per tool: from `docs/part2-notes.md`, the refactor regression run took 440.9 s and the recorded 15-transcript run took 2,064.6 s ($4.88). Submit / stream / fetch survives proxies and a closed plugin window; the draft contract in `surfaces/mcp/remote.py` (synchronous calls) will be replaced.
- 2026-09-04 — Privacy line in the spec ("processed for the run and discarded; nothing stored") maps onto the logger's existing `redact=True`: digests instead of prompt bodies, no corpus snapshot. The hosted service keeps the processed corpus in memory for the job plus a short TTL, then drops it. Consequence: remote `motif_receipts` only works within the TTL; the plugin gets receipts inline in the insights and never needs the endpoint.
- 2026-09-04 — Editor gap: stickies and connectors are FigJam-only plugin-API nodes; the Design editor has sections but no stickies. The board writer needs a second renderer (frames and text) for Design. Proposed order: FigJam first, Design at the end of stage 3.
- 2026-09-04 — Payments constraint: Figma's payments API sells one-time purchases or subscriptions, not a consumable balance, so prepaid credits need an ETOT-owned ledger topped up by Stripe Checkout via webhook. Matches the spec's Stripe fallback. To verify against Figma's docs when the paid tier is built.
