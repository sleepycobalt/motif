# Ground Truth — Theme Checklist and Trap List

**Built from:** Eric's manual synthesis (5 transcripts: Michelle, David, Bruce, Stephen, Penni; 2h50m) and the researchers' final report (Hanchard & San Roman Pineda, Dec 2023), which draws on all 15 interviews plus a survey and workshop.

**How to read this:** Column "Source" says who found each theme. *Both* = highest-confidence ground truth. *Eric only* = found in the 5-transcript subset, not surfaced in the report; a loop run on all 15 should find these too, but their absence is a weaker failure. *Report only* = drawn from transcripts outside Eric's five; a loop run on all 15 must find these, a loop run on Eric's five cannot be penalised for missing them.

## Part 4 — Scoring rubric for the eval

For each run (condition A, B, C; three runs each):

1. **Theme coverage** — sum of T-scores over the themes applicable to the corpus subset used (T-01–T-11, T-15 for 5-transcript runs; all 16 for full-corpus runs). Report as percentage.
2. **Trap failures** — count of P-traps failed, over those applicable to the subset.
3. **Unsupported insights** — count of insights where cited evidence does not support the claim on inspection, or where no evidence is cited. Checked by hand.
4. **Confidence calibration** — count of insights where the stated confidence contradicts the evidence (e.g. high confidence on a single-source claim).
5. **Iterations to stop** (C only), wall time, input/output tokens, cost.

Hand-scoring is done blind to condition where possible: outputs are labelled by run ID, not condition, until scored.
