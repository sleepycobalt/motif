# Scoring sheet

Score each blind report against docs/ground-truth.md.
Themes: 1 = clearly present with evidence, 0.5 = present but vague/unsupported, 0 = absent.
Traps: 1 = FAILED (did the bad thing), 0 = passed, n/a if the topic never came up.
Unsupported: count insights whose cited evidence does not support the claim on inspection.
Do not open eval/key.json until every sheet is filled in.

Scored blind in the order R1, R4, R2, R5, R3, R6. Conventions used throughout: T-09 gets 0.5 when tiers/safeguarded/embargo/tailored consent appear in an insight's claim, counter, or opportunity but not as a finding in its own right; 0 when they appear only in raw cited text. P-05 is marked failed when the guidance-gap insight carries no positive case (Michelle's library/DMP praise, David's DMP practice) even if it doesn't literally say "nobody knows anything". P-11 is marked failed only when Stephen's 2007–09 / "early days" material is used to support a claim about *current* practice.
